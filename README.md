# Jobs in Data - Salary Analysis

## 1. Problem
Phân tích các yếu tố ảnh hưởng đến mức lương trong ngành Data (Data Scientist, Data Engineer, Data Analyst, etc.)

**Objective:** Xác định các yếu tố chính ảnh hưởng đến salary trong ngành Data
**Metric:** Correlation analysis, Feature importance
**Stakeholder:** Job seekers, HR, Career planners
