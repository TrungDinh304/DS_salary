# Power BI Dashboards

## Files
- `salary_dashboard.pbix` - Main dashboard file

## Data Source
- Connect to: `../data/processed/cleaned_data.csv`
- Use **Import** mode (data is small)

## Setup Instructions
1. Open `.pbix` file in Power BI Desktop
2. Update data source path if needed:
   - Home > Transform data > Data source settings
3. Refresh data
